# FoodProcessPortal

Віртуальний підручник з дисципліни "Процеси і апарати харчових виробництв" для студентів харчових технологій.

Проєкт побудований як статичний Astro-сайт із мультимовним навчальним контентом, лабораторними роботами, задачником, методичними матеріалами та інтерактивними довідковими калькуляторами.

## Можливості

- Теми і лекції з основних розділів дисципліни.
- Задачник із розрахунковими формулами, прикладами та контрольними задачами.
- Практикум із лабораторними роботами за категоріями.
- Довідник із калькуляторами властивостей води, теплоносіїв і харчових продуктів.
- Курсові матеріали з методиками розрахунку обладнання.
- Мультимовність: українська, англійська, російська, німецька.
- Світла, темна та автоматична тема інтерфейсу.

## Контент

Основний контент живе у `src/content`:

- `topics/{locale}` - сторінки тем.
- `lectures/{locale}/{topic}` - лекції всередині тем.
- `practice/{locale}` - категорії практикуму.
- `labs/{locale}/{category}` - лабораторні роботи.
- `problems/{locale}/{topic}` - розділи задачника.
- `courses/{locale}/{course}` - курсові та методичні матеріали.

Frontmatter перевіряється через Astro content collections у `src/content.config.ts`.

## Локалізація

Активні мови задаються у `src/locales.config.ts` через `ENABLED_LOCALES`. Основні UI-переклади зберігаються у `src/config.ts`, а короткі спільні підписи для довідника — у `src/locales.config.ts`.

## SEO

Основний домен задається один раз у `src/config.ts` як `siteConfig.url` і використовується Astro config, sitemap, robots та layout-метаданими.

Генеруються:

- canonical URL;
- hreflang-посилання;
- Open Graph і Twitter meta;
- `robots.txt`;
- `sitemap-index.xml`.

## Поточний стан

Сайт збирається як статичний проєкт і генерує сторінки для активних локалей. Український контент є основним; для частини лабораторних сторінок інші локалі використовують fallback на український контент.
