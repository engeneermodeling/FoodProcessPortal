# Рисунок поруч із відео

На слайдах 4, 5, 7, 22, 32 відео й відповідне початкове фото або схема тепер показуються одночасно. На комп’ютерах вони стоять поруч: ілюстрація ліворуч, відео праворуч. Основні тези розташовано над ними. На екранах до 900 px медіа йдуть одне за одним.

Використано наявні елементи й медіафайли без копіювання чи заміни їхнього змісту. Збережено підписи, посилання на джерела, збільшення фотографій, повзунок відео, ±10 секунд, швидкість і повноекранний перегляд. Зайвий перемикач «Показати фото» приховано для парного вигляду, оскільки фото вже видно. Порожні слоти для майбутніх локальних відео зберігають попередній вигляд до вибору файлу.

Перевірено всі п’ять пар на 1280 × 800 та 375 × 812 px: обидва медіа видимі, на комп’ютері стоять поруч, на телефоні послідовно. Перевірено збільшення фотографії на слайді 4, відтворення/перемотування, швидкість 2×, повернення до лекційного фрагмента, повноекранне відео й вибір локального файлу.

Повторна перевірка всіх 43 слайдів на п’яти розмірах екрана пройшла: стала рамка та навігація збережені, помилок JavaScript немає. Наявна перевірка презентації також пройшла: 43 слайди, 80 хвилин, 5 відео, 8 відеослотів.

Змінено:
- `public/presentations/mixing/presentation.js` — компонування наявних відео та ілюстрацій поруч.
- `public/presentations/mixing/presentation.css` — два стовпці для медіа, тези над ними та адаптація для телефонів.

Знімки й результати перевірок: `docs/mixing-paired-media-review/`. Докази перевірок попереднього оформлення оновлено в `docs/mixing-media-review/` та `docs/mixing-viewport-review/`. HTML зі змістом слайдів, зображення, відеофайли, videos.json, нотатки та DOCX під час цього завдання не змінювалися. Пуш і публікація не виконувалися.

Фінальна збірка Astro успішна: 612 сторінок. Зібрані CSS/JS звірено з вихідними файлами.
