# Керування мовами FoodProcessPortal

Портал має статичну збірку Astro. Адміністратор із доступом до репозиторію може вмикати й вимикати додаткові мови через команди або конфігурацію. Зміна застосовується до всього сайту після збірки, а не лише до поточного браузера.

## Команди адміністратора

Виконувати з кореня FoodProcessPortal:

```sh
node scripts/manage-languages.mjs list
node scripts/manage-languages.mjs disable ru
node scripts/manage-languages.mjs enable ru
node scripts/manage-languages.mjs disable de
node scripts/manage-languages.mjs enable en
```

Коди: `uk` — українська, `en` — англійська, `ru` — російська, `de` — німецька. Українська є обов’язковою основною мовою: її використовують резервні переклади й окремі фіксовані маршрути, тому вимкнення `uk` відхиляється з поясненням.

Поточні налаштування збережено в `src/language-settings.json`:

```json
{
  "uk": true,
  "en": true,
  "ru": true,
  "de": true
}
```

`true` вмикає мову, `false` вимикає. Невідомі коди, пропущені мови та значення, відмінні від true/false, відхиляються, щоб уникнути неповної збірки. Наразі всі чотири мови залишено увімкненими; тестове вимкнення відновлено.

## Як застосувати

1. Змінити налаштування командою або редагуванням JSON.
2. Для локального перегляду перезапустити `npm run dev`.
3. Виконати `npm run build` для нової статичної збірки.
4. Для зміни доступності мов на опублікованому сайті потрібне окреме розгортання нової збірки. Під час цього завдання сайт не публікувався.

Вимкнена мова зникає зі стартового вибору мов, меню перемикання та sitemap. Її сторінки, лекції й задачі не генеруються в новій збірці, тому прямі посилання на них повертають 404 на статичному хостингу. Файли перекладів зберігаються й знову використовуються після ввімкнення. Навчальні матеріали, відео, презентація та DOCX не редагуються.

## Межі реалізації

Це керування адміністратором через репозиторій. Захищеної вебадмінпанелі, облікових записів і серверної бази налаштувань у поточному проєкті немає. Для перемикання в браузері без нової збірки потрібна окрема реалізація авторизації та серверного збереження. Перемикач на localStorage не використовується, оскільки він змінював би лише один браузер.

## Перевірка

```sh
node scripts/check-language-settings.mjs
```

Перевіряються вмикання/вимикання, валідація та реальні операції команд адміністратора в окремій тимчасовій папці; робоча конфігурація не змінюється. Окремо перевірено повну збірку з тимчасово вимкненою `ru`: каталог `/ru`, посилання на стартовій сторінці й у меню, а також записи sitemap відсутні. Початкові налаштування відновлено.

## Файли реалізації

- `src/language-settings.json` — постійні перемикачі мов.
- `src/utils/language-settings.mjs` — спільна перевірка налаштувань.
- `src/locales.config.ts` — підключення перемикачів до існуючих споживачів ENABLED_LOCALES.
- `scripts/manage-languages.mjs` — команди адміністратора.
- `scripts/check-language-settings.mjs` — перевірки.
- `src/pages/[locale]/topics/[topic]/[lecture].astro` та `src/pages/[locale]/problems/[chapter]/index.astro` — фільтрація маршрутів вимкнених мов.

## Наступний етап

За домовленістю з власником порталу в майбутньому потрібно створити захищену адмінпанель, сторінку студента та сторінку викладача. Ці сторінки й авторизація не входять до поточного впровадження перемикачів мов. Майбутня адмінпанель має використовувати спільну перевірку налаштувань із `src/utils/language-settings.mjs`.

Фінальна перевірка збірок: з тимчасово вимкненою `ru` — 467 сторінок; після відновлення всіх чотирьох мов — 612 сторінок. Обидві збірки успішні.
