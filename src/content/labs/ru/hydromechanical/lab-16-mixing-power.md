# Лабораторная работа №16. Определение расхода энергии при механическом перемешивании в жидкой среде

## Основные теоретические положения

Для образования эмульсий, суспензий, для интенсификации тепло- и массообменных процессов применяют механическое перемешивание в жидкой среде. Эффективность перемешивания определяется расходом энергии на вращение мешалки, необходимым для достижения требуемого технологического результата.

## Порядок выполнения работы

Перед началом работы определяем диаметр мешалки, диаметр сосуда и физические характеристики исследуемой среды: температуру, плотность и коэффициент динамической вязкости.

Включаем электродвигатель и устанавливаем заданную частоту вращения вала мешалки с помощью ручки автотрансформатора. По циферблату весов определяем окружные усилия, соответствующие моментам мешалки при заданных частотах вращения. В таблицу записываем значения частоты вращения n и окружного усилия P. Выключаем электродвигатель. Остальные величины вычисляем с помощью соответствующих формул, приведённых в таблице.
