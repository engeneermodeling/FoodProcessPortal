# Лекція 8. Основи перемішування у харчових апаратах

## Що ви дізнаєтесь

Після цієї лекції ви зможете:

- пояснити, чому **одна й та сама мішалка** може бути вдалою для сиропу і невдалою для томатного пюре
- розрізняти задачі **розчинення, суспендування, емульгування, гомогенізації, теплообміну і газорідинного диспергування**
- обчислювати число Рейнольдса мішалки `Re_m`
- оцінювати потужність приводу через критерій потужності `N_p`
- вибирати тип мішалки за в'язкістю продукту і технологічною метою
- помічати практичні ризики: піноутворення, пригар, мертві зони, пошкодження структури продукту

---

## 1. Навіщо харчовому апарату перемішування

Перемішування не є самоціллю. У виробництві нас цікавить не "щоб воно крутилося", а щоб продукт став однорідним, стабільним, без грудок, без осаду, без перегріву і з потрібною текстурою.

![Карта задач перемішування у харчових виробництвах](/images/lectures/mixing/mixing-tasks-map.svg)

Типові харчові задачі:

| Задача | Приклади продуктів | Що контролюємо |
|---|---|---|
| **Розчинення** | цукровий сироп, розсіл, сольові суміші | час розчинення, температура, відсутність кристалів |
| **Суспендування** | какао-напої, томатна маса, спеції в маринаді | частинки не осідають на дно |
| **Емульгування** | майонез, соуси, молочно-жирові суміші | розмір крапель, стабільність емульсії |
| **Гомогенізація складу** | купажі соків, молочні напої, сиропи | однакова концентрація у всьому об'ємі |
| **Інтенсифікація теплообміну** | варіння джему, креми, згущені продукти | менше пригару, рівномірна температура |
| **Газорідинне диспергування** | аерація десертів, карбонізація напоїв | розмір бульбашок, піноутворення |

## 2. Властивості продукту визначають мішалку

Ключові властивості:

- **густина** `rho`, кг/м³
- **динамічна в'язкість** `mu`, Па·с
- наявність твердих частинок, жиру, повітря, кристалів або волокон
- чутливість до зсуву: йогурт, вершкові креми й фруктові наповнювачі можна зіпсувати надмірно інтенсивним перемішуванням
- температура: в'язкість джему, сиропу або шоколадної маси сильно залежить від нагрівання

Практичне правило: зі зростанням в'язкості потрібно переходити від швидкохідних пропелерних і турбінних мішалок до тихохідних якірних, рамних, шнекових або стрічкових конструкцій. Для дуже в'язких продуктів часто потрібні скребки біля стінки, інакше шар біля сорочки перегрівається.

## 3. Типи потоків у апараті

![Типові потоки в апараті з мішалкою](/images/lectures/mixing/impeller-flow-patterns.svg)

| Тип потоку | Що робить | Типові мішалки | Харчові приклади |
|---|---|---|---|
| **Осьовий** | переносить продукт зверху вниз або знизу вгору | пропелерна, лопатева | розсоли, сиропи, суспензії з невеликою в'язкістю |
| **Радіальний** | відкидає потік до стінок, створює високий зсув | турбінна | емульсії, диспергування порошків, соуси |
| **Тангенціальний** | обертає масу по колу | якірна, рамна | джеми, креми, шоколадні й карамельні маси |

Якщо в апараті без перегородок утворюється воронка, частина енергії витрачається не на перемішування, а на обертання всього об'єму. Для малов'язких рідин ставлять **відбивні перегородки**. Для в'язких продуктів перегородки можуть заважати очищенню або створювати застійні зони, тому рішення залежить від продукту.

## 4. Число Рейнольдса мішалки

Для апарата з мішалкою режим руху оцінюють не через швидкість у трубі, а через частоту обертання і діаметр мішалки:

```text
Re_m = rho · n · d_m² / mu
```

де:

- `rho` — густина продукту, кг/м³
- `n` — частота обертання, с⁻¹
- `d_m` — діаметр мішалки, м
- `mu` — динамічна в'язкість, Па·с

Орієнтовно:

| Режим | Діапазон `Re_m` | Що це означає |
|---|---:|---|
| **Ламінарний** | `< 10` | перемішування повільне, домінує в'язкість |
| **Перехідний** | `10 ... 10 000` | результат сильно залежить від форми мішалки й апарата |
| **Турбулентний** | `> 10 000` | інтенсивні пульсації, швидке вирівнювання складу |

![Режими перемішування і критерій потужності](/images/lectures/mixing/mixing-power-regimes.svg)

## 5. Потужність приводу

Для турбулентного режиму потужність часто оцінюють через критерій потужності:

```text
N_p = N / (rho · n³ · d_m⁵)
```

Звідси:

```text
N = N_p · rho · n³ · d_m⁵
```

де `N` — потужність, Вт. Значення `N_p` беруть з довідників або графіків для конкретного типу мішалки. Для турбінних мішалок порядок величини часто становить `4 ... 6`, для пропелерних може бути значно меншим.

Важливий висновок: потужність дуже чутлива до швидкості та діаметра. Якщо збільшити `n` у 2 рази, у турбулентній області потужність зростає приблизно у `2³ = 8` разів. Якщо збільшити `d_m` у 2 рази — приблизно у `2⁵ = 32` рази.

## 6. Приклад розрахунку

**Задача.** У резервуарі готують цукровий сироп. Дано:

- густина `rho = 1150 кг/м³`
- в'язкість `mu = 0,015 Па·с`
- діаметр мішалки `d_m = 0,40 м`
- частота обертання `n = 3 с⁻¹`
- для турбінної мішалки прийняти `N_p = 5`

**1. Режим перемішування**

```text
Re_m = 1150 · 3 · 0,40² / 0,015 = 36 800
```

`Re_m > 10 000`, отже режим турбулентний.

**2. Потужність на валу**

```text
N = 5 · 1150 · 3³ · 0,40⁵
N = 5 · 1150 · 27 · 0,01024 = 1590 Вт ≈ 1,6 кВт
```

Для реального приводу беруть запас 20...30%, тому найближчий двигун може бути близько **2,2 кВт**.

**3. Що зміниться для пюре?**

Якщо замість сиропу продукт має `mu = 2 Па·с`, то:

```text
Re_m = 1150 · 3 · 0,40² / 2 = 276
```

Це вже перехідна область. Турбінна мішалка може створювати локальне перемішування, але весь об'єм рухатиметься гірше. Для пюре, джему або крему часто доцільніші якірні, рамні або скребкові мішалки.

## 7. Вибір мішалки для харчових продуктів

| Мішалка | Де доречна | Перевага | Обмеження |
|---|---|---|---|
| **Пропелерна** | вода, молоко, розсоли, сиропи малої в'язкості | швидке осьове перемішування | погано працює у дуже в'язких масах |
| **Турбінна** | емульсії, суспензії, розчинення порошків | інтенсивний зсув | може пошкоджувати ніжну структуру |
| **Лопатева** | прості рідкі суміші, супові основи | конструктивно проста | невисока інтенсивність |
| **Якірна / рамна** | джем, крем, шоколадна маса, карамель | добре переміщує в'язкі продукти біля стінки | повільніша, потребує більшого моменту |
| **Шнекова / стрічкова** | дуже в'язкі пасти й начинки | створює циркуляцію у в'язкому об'ємі | складніше миття і вища ціна |

## 8. Санітарія і якість

У харчовому апараті конструкція мішалки має бути не лише "розрахунково правильною", а й гігієнічною:

- мінімум щілин, мертвих зон і різьбових порожнин у контакті з продуктом
- можливість CIP-миття або швидкого розбирання
- гігієнічне ущільнення вала
- контроль піни й небажаного захоплення повітря
- обережність з продуктами, чутливими до зсуву: йогурт, вершкові десерти, фруктові шматочки
- контроль температури біля стінки, особливо для цукровмісних і білкових систем

## 9. Міні-практикум

1. Чому для малов'язкого сиропу і густого джему не варто автоматично брати одну й ту саму мішалку?
2. У скільки разів зросте потужність у турбулентній області, якщо збільшити частоту обертання з `2 с⁻¹` до `3 с⁻¹`?
3. Для продукту `rho = 1050 кг/м³`, `mu = 0,08 Па·с`, `d_m = 0,35 м`, `n = 2,5 с⁻¹` обчисліть `Re_m` і визначте режим.
4. Поясніть, чому перегородки корисні для водних розчинів, але не завжди зручні для в'язких кремів.

## 10. Коротко

- Перемішування проектують від **технологічної мети**, а не від бажання поставити "потужнішу мішалку".
- Головний безрозмірний критерій для режиму — `Re_m = rho · n · d_m² / mu`.
- У турбулентній області потужність оцінюють як `N = N_p · rho · n³ · d_m⁵`.
- В'язкість різко змінює поведінку апарата: те, що добре працює для сиропу, може бути невдалим для пюре або крему.
- Для харчових виробництв важливі не тільки гідродинаміка, а й санітарія, миття, піна, пригар і текстура продукту.
